WS2812B RGB LEDs

Hardware ID: 014 · PCB revision: 0.1

Purpose

Three WS2812B-2020 addressable RGB LEDs with a data chain-out.

Power and connection limits

Vinyan supplies 3.3 V. This is below the WS2812B-2020 documented 3.7 V minimum and remains a hardware qualification limitation.

Connectors

  • Input / Vinyan OUT1/OUT2 / JST XH 3-pin: 1=3V3, 2=DIN, 3=GND.
  • Chain-out / JST XH 3-pin: 1=3V3, 2=DOUT, 3=GND.

Usage and revision notes

  • Addressable LEDs receive a single-wire data stream; DOUT chains to another board.
  • Operation at 3.3 V is not guaranteed by the quoted device supply specification. Verify brightness, colour and reliable startup on actual hardware.
