Rotary potentiometer

Hardware ID: 009 · PCB revision: 0.1

Purpose

Rotary potentiometer providing an analog input to Vinyan.

Power and connection limits

3.3 V only; wiper output spans approximately 0–3.3 V.

Connectors

  • Vinyan IN1–IN4 / JST XH 3-pin: 1=3V3, 2=POT, 3=GND.

Usage and revision notes

  • The circuit uses a 10 kΩ potentiometer with filtering on the wiper.
  • ESP32 ADC response is nonlinear near the upper end of the input range.
