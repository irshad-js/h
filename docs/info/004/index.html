BH1750 ambient-light sensor

Hardware ID: 004 · PCB revision: 0.1

Purpose

BH1750 ambient-light sensor for the Vinyan I2C chain.

Power and connection limits

3.3 V only. Do not connect to 5 V.

Connectors

  • Vinyan J1 / JST XH 4-pin: 1=3V3, 2=GND, 3=SDA, 4=SCL. Parallel chain-out uses the same order.

Usage and revision notes

  • I2C address is 0x23 by default; the address jumper can select 0x5C.
  • Optional I2C pull-ups and power LED jumpers are open by default. Vinyan supplies I2C pull-ups.
  • The BH1750 land pattern requires datasheet verification before fabrication.
