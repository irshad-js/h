DHT11 temperature/humidity sensor

Hardware ID: 006 · PCB revision: 0.1

Purpose

DHT11 temperature and humidity sensor with a single-wire data connection.

Power and connection limits

3.3 V accessory port only.

Connectors

  • Vinyan OUT1/OUT2 / JST XH 3-pin: 1=3V3, 2=DATA, 3=GND. OUT1/OUT2 use IO26/IO27.

Usage and revision notes

  • The board provides a 10 kΩ data pull-up.
  • Use OUT1/OUT2; IN3/IN4 are input-only and cannot drive the sensor's request pulse.
