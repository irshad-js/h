LED matrix 8×8 0805

Hardware ID: 018 · PCB revision: 1.0

Purpose

Passive 8×8 matrix with 64 discrete 0805 LEDs.

Power and connection limits

No onboard driver or standalone supply input. Row/column drive and current limiting belong to the compatible host.

Connectors

  • J1/J2 are eight-pin row/column headers. Verify their printed pin labels against the host before connecting.

Usage and revision notes

  • This is the 0805 base design used by the 16×8 0805 panel. This page identifies PCB revision 1.0.
