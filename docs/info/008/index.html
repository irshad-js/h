SSD1306 OLED carrier

Hardware ID: 008 · PCB revision: 0.1

Purpose

Carrier for a 0.96-inch SSD1306 I2C OLED display.

Power and connection limits

3.3 V accessory port only. Verify the display module's supply pins before insertion.

Connectors

  • Vinyan J1 / JST XH 4-pin: 1=3V3, 2=GND, 3=SDA, 4=SCL; parallel chain-out.
  • Display socket order: GND, VCC, SCL, SDA. Some modules swap GND/VCC; check your module.

Usage and revision notes

  • Typical I2C address is 0x3C; some modules use 0x3D.
  • The display module can overhang the carrier. Use appropriate mounting standoffs.
  • Optional I2C pull-ups are open by default.
