LED matrix 16×8 0402

Hardware ID: 015 · PCB revision: unversioned

Purpose

Passive 16×8 matrix with 128 discrete 0402 LEDs for Vinyan's external matrix drivers.

Power and connection limits

No onboard driver or standalone supply input. Connect only to the compatible host matrix driver with verified orientation.

Connectors

  • Matrix A carries ROW0–ROW7 and COL0–COL7 to Vinyan J11/J14 pins 9–16.
  • Matrix B carries ROW8–ROW15 and COL0–COL7 to Vinyan J11/J14 pins 1–8. Match the printed row/column labels before connecting.

Usage and revision notes

  • This current source has no PCB title-block revision. Its permanent ID identifies the recorded unversioned source, not every future 0402 matrix.
  • The two 8×8 sections have separate row lines; column lines join at the host.
