LED matrix 16×8 0805

Hardware ID: 016 · PCB revision: 1.0

Purpose

Passive 16×8 matrix with 128 discrete 0805 LEDs for Arivaan's large-display headers.

Power and connection limits

No onboard driver or standalone supply input. Verify host driver compatibility and header orientation before connecting.

Connectors

  • Matrix A: J1008 pins 1–8 carry B1–B8; J1006 pins 9–16 carry C1–C8.
  • Matrix B: J1009 pins 1–8 carry B9–B16; J1007 pins 9–16 carry C9–C16.

Usage and revision notes

  • The matrix is passive; LED drive and current limiting belong to the host.
  • Header rows are 24.0 mm apart and the two module centres are 32.265 mm apart.
