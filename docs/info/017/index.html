LED matrix 8×8 0402

Hardware ID: 017 · PCB revision: unversioned

Purpose

Passive 8×8 matrix with 64 discrete 0402 LEDs.

Power and connection limits

No onboard driver or standalone supply input. Row/column drive and current limiting belong to the compatible host.

Connectors

  • J1/J2 are eight-pin row/column headers. Verify their printed pin labels against the host before connecting.

Usage and revision notes

  • This current source has no PCB title-block revision. Its permanent ID identifies the recorded unversioned source.
  • This is the 8×8 base design used by the 16×8 0402 panel.
