12×12 mm push button

Hardware ID: 010 · PCB revision: 0.1

Purpose

12×12 mm momentary push button with active-low output and RC debounce.

Power and connection limits

3.3 V accessory port only.

Connectors

  • Vinyan IN1–IN4 / JST XH 3-pin: 1=3V3, 2=BTN, 3=GND.

Usage and revision notes

  • Pressed reads low. The board provides a 10 kΩ pull-up and 100 nF debounce capacitor.
  • The onboard pull-up permits use on IN3/IN4, which have no internal pull-up.
