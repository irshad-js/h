# Security

Report vulnerabilities privately to irshad9in@gmail.com. Do not post credentials
or exploit details in public issues.

The only supported branch is main. Destination edits are security-sensitive:
review HTTPS hosts and route identity before publishing. Never accept a redirect
destination from a URL query, fragment, form, or visitor-supplied registry.

Account/repository takeover can change printed QR destinations. Protect the
owner account with strong multifactor authentication and review repository access.
